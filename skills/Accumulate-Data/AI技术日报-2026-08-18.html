六、本周值得阅读论文（Top 5）

1. Harness-R1：让 Agent 自己改 Harness

机构：上海交大 + 多机构联合（arXiv:2608.02276，提交 8/2）

创新点：从 Agent 失败轨迹学习，自动生成对可执行 Runtime Harness 的编辑操作（直接修改 Agent 调用框架本身而非提示词）。WebShop/ALFWorld/GAIA 提升 30-138%。

阅读难度：★★★★

是否值得深入阅读：是——兑现了 Lilian Weng「短期内最先被改写的是 Harness 而不是模型权重」的预言。

一句话总结：把 Harness 变成可被 Agent 迭代训练的对象，Harness Engineering → Self-Improving Harness。

2. SHE：安全护栏也可以从失败轨迹中演化

机构：上海 AI 实验室 + 复旦 + 上海交大 + 香港科大（arXiv，提交 8/10）

创新点：把护栏拆成 System Prompt/Rule Bank/Safety Memory/Tool Policy 四个可编辑工件。Agent-SafetyBench 攻击成功率 17.1% → 5.5%，良性可用率 31.6% → 47.6%。

阅读难度：★★★

是否值得深入阅读：是——所有做 Agent Harness 的工程师必读。

一句话总结：把安全责任拆开，让每次失败都能落到可回滚的局部修改。

3. RestoreKV：修复 AI 激进压缩记忆的性能断崖

机构：釜山国立大学 + 淑明女子大学（arXiv:2608.01247）

创新点：在 KV Cache 压缩前先让模型学会「写一份精华摘要」，保存为 Restore Cache 补丁，避免查询无关驱逐时性能断崖。

阅读难度：★★★

是否值得深入阅读：是——长上下文场景必读。

一句话总结：与其争论留哪几页，不如给压缩后的速记员加一份「摘要补丁」。

4. U-OPSD：让模型用自己的共识修正自己

机构：UC San Diego + Georgia Tech + UMD + ByteDance（arXiv:2608 提交 8/6）

创新点：在无标签问题上采样多条 rollout，用多数票构造伪解，把错误完成作为学生轨迹做 token 前缀蒸馏。Qwen3 非思考模式 4B/8B 提升 8.5%/10.7%。

阅读难度：★★★

是否值得深入阅读：中——无标签后训练场景值得借鉴。

一句话总结：把「自我改进」落成可检查的 rollout 过滤和错误前缀蒸馏。

5. Video-DeepResearch：让 AI「先看视频再搜网络」

机构：中科大 + 小红书 + 港中文 + 浙大 + UCLA + 牛津 + 清华（arXiv:2608.03979，提交 8/4）

创新点：强制「先看视频再搜网络」的训练策略，35B 开源模型以 64% 准确率超越 GPT-5 和 Claude-4.5-Sonnet。

阅读难度：★★★★

是否值得深入阅读：是——视频研究/多模态 Agent 必读。

一句话总结：让 AI 像人一样「先看再搜」，多模态 Agent 的新范式。
