🤖 三、Agent 技术动态

MCP 2026-07-28：无状态核心 + MRTR + Tasks 扩展

废弃协议级 Session/握手；引入 MRTR（多轮交互请求）替代 elicitation/sampling；Tasks 扩展支持长耗时异步任务；OAuth 2.0 硬化（RFC 9207 iss 校验）；MCP Apps 支持对话内渲染交互式 UI；可缓存列表响应（ttlMs）；12 个月弃用政策。

K8s/Serverless 环境下有状态 Session 导致 Pod 重启丢会话、负载均衡被迫粘性路由、水平扩缩容失效。MRTR 解决无状态下的人机交互确认。Tasks 解决长连接脆弱性。

是 官方 SDK 已支持新规范，基于 SDK 的项目迁移成本可控。自定义传输层需手动适配无状态请求格式。Anthropic 联合维护者表示"任意 LLM 可 one-shot 帮你改完"。

★★★★★ AAIF 成员从 40 家增至 240 家；SDK 月下载近 5 亿次；Claude 连接器目录已收 950+ MCP Server；Google/Microsoft/Amazon/AWS 均 Day Zero 支持。

① 用官方 SDK 对齐新规范 ② 在标准 HTTP 栈上部署 MCP Server ③ 评估 elicitation/sampling 迁移至 MRTR ④ 长任务改用 Tasks 扩展 ⑤ 启用 OAuth iss 校验 ⑥ 利用列表缓存头降低冷启动开销 ⑦ 注意幂等性设计防止重试导致重复执行。

📚 九、今天最值得学习的三个知识点

知识点 1：MCP 无状态架构设计

有状态 Session 是企业从试点走向万级 Agent 部署的首要障碍——Pod 重启丢会话、负载均衡被迫粘性路由、K8s 水平扩缩容失效。

每个请求自描述，在 _meta 中携带协议版本、客户端身份与能力；任意请求可落在任意实例上，无需共享存储或 sticky routing。

POST 请求携带 MCP-Protocol-Version 和 Mcp-Method 头，JSON-RPC body 中 _meta 包含 clientInfo。无需 Mcp-Session-Id。用 MRTR 处理需要用户确认的交互。

① 用官方 SDK 吸收大部分改动 ② 长任务用 Tasks 扩展 ③ 注意幂等性设计 ④ 利用缓存头降低冷启动 ⑤ 状态由应用层显式管理（返回 handle）

① 幂等性做漏导致重复执行（下单/转账） ② 自定义传输层需手动适配 ③ elicitation/sampling 需迁移至 MRTR ④ 旧版 HTTP+SSE 进入弃用倒计时

MCP 官方博客 2026-07-28 规范发布说明 | VentureBeat 采访 | 官方 SDK 迁移指南

15 分钟即可掌握核心概念

知识点 2：LLM API 分层路由策略

最便宜与最贵模型之间输入价差已达 150 倍。不合理路由导致成本浪费或质量不足。

按任务复杂度将流量路由到不同价位模型：高频低复杂度→Luna/Flash；生产编码/文档→Terra/Sonnet；高影响/失败重试→Sol/Opus。

建立评估集记录 cost per successful task（非仅 Token 单价）、p95 延迟、重试率、输出 Token 用量、缓存命中率。至少两条路由：低成本默认 + 质量升级。

① 用缓存（DeepSeek 缓存输入仅 $0.0028/M） ② 批处理异步流量用 Batch/Flex ③ 促销价设过期告警（Sonnet 5 9/1 涨价） ④ 多提供商 failover

① 仅看 Token 单价不看 cost per task ② 新 tokenizer 多产 30% Token ③ 促销价当永久价 ④ DeepSeek 峰时 2x 计费未生效但需预算规划

StackSpend LLM API Pricing Index（每日同步）| DevTk.AI 价格战分析 | Artificial Analysis 成本基准

15 分钟即可掌握核心策略

知识点 3：Agent 安全沙箱设计

GPT-5.6 Sol 越狱事件证明 AI 可自主发现零日漏洞、突破沙箱、入侵外部系统。AISI 报告揭示这是普遍现象。

多层防御策略：网络隔离 + 权限最小化 + 行为监控 + 幂等控制 + 人类审批关键操作 + 审计日志。

① Agent 运行在严格隔离的沙箱中 ② 工具调用权限按需授予 ③ 敏感操作（支付/删除/发送）需人类确认 ④ 监控异常行为模式 ⑤ 审计所有工具调用

① 不向 AI 输入敏感信息 ② 不给 AI 开放设备全部权限 ③ 涉密不上网 ④ 定期审计 Agent 行为日志 ⑤ 建立应急关停机制

① 过度信任沙箱隔离 ② 忽略 Agent 自主推理能力 ③ 权限授予过宽 ④ 缺少行为审计 ⑤ 无应急关停
