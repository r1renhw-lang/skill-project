九、今天最值得学习的三个知识点

知识点 1：Agent 框架的插件化架构设计

为什么需要

传统 Agent 框架将模型接入、工具调用、会话管理、安全策略等耦合在一起，导致难以定制和替换。企业需要根据自身需求灵活组装 Agent 能力。

是什么

以 DeepSeek Harness 为代表的"一切皆插件"架构，基于微内核（如 Cordis），将所有 Agent 能力（模型、工具、技能、会话、沙箱、存储、调度、UI）拆分为独立插件，通过配置文件组合。

怎么使用

安装 Node.js 后运行 npx deepseek-ai/dsh web 启动 Web UI，在配置中选择所需插件组合。可自定义模型接入、工具注册、安全策略。

最佳实践

从极简模式开始，逐步添加插件。使用仅追加会话日志系统进行调试和回放。

容易踩坑

插件间依赖关系复杂，移除某个插件可能影响其他插件功能。v0.1 版本 API 可能变更。

推荐资料

GitHub: deepseek-ai/deepseek-harness

学习时间

15 分钟即可理解核心概念，1 小时可跑通 Demo

知识点 2：Claude Code Auto Mode 的分类器安全审查机制

为什么需要

人工审批存在严重的"确认疲劳"——用户在 Claude Code 中批准 97% 的权限确认弹窗，导致安全审批形同虚设。

是什么

Auto Mode 使用独立分类器模型（默认 Claude Sonnet 5）实时审查每个操作。分类器读取对话上下文判断操作合理性，拦截破坏性/越权/不可逆操作（如 curl|bash、force push、生产部署等）。

怎么使用

Pro/Max/Team 用户今日起自动启用。可用 Shift+Tab 切换模式。可配置自定义硬性拒绝规则。

最佳实践

配置企业级硬性拒绝规则（如禁止外部数据传输、禁止生产环境部署）。连续 3 次被拦截或单次会话 20 次被拦截会自动降级为手动模式。

容易踩坑

分类器默认允许 push 到默认分支（之前只允许 push 到 Claude 创建的分支）。.git、.claude、shell profile 等受保护路径在任何模式下都不会自动批准。

推荐资料

Anthropic 官方公告 + Claude Code 文档

学习时间

15 分钟即可掌握配置和使用

知识点 3：低成本 Agent 模型的选型策略

为什么需要

企业部署 Agent 需要平衡能力与成本。Flash 级模型迭代加快，价格战激烈，选型直接影响 ROI。

是什么

当前低成本 Agent 模型梯队：Gemini 3.7 Flash（$0.75/$3.75，FrontierCode 43.6%）、DeepSeek V4 Flash（$0.14/$0.28）、GPT-5.6 Luna（$1/$6）、GPT-5.6 Terra（$2.5/$15）。

怎么使用

按场景分层：简单提取/路由用 Luna 级，生产工作流用 Terra/Flash 级，复杂推理用 Sol/Pro 级。利用 Gemini 3.7 Flash 年底前半价策略降低成本。

最佳实践

使用模型网关（如 NVIDIA Switchyard）实现多模型路由和故障转移，按任务复杂度动态选择模型层级。

容易踩坑

Gemini 3.7 Flash 半价为年底前推介价，2027 年 1 月起恢复 $1.5/$7.5。成本测算需按恢复价计算。

推荐资料

各模型官方定价页 + Artificial Analysis 综合测评

学习时间

15 分钟即可掌握选型框架
