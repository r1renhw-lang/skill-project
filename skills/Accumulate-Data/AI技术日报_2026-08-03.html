★ 九、今天最值得学习的三个知识点

知识点 1：后训练（Post-Training）优化的杠杆效应

为什么需要：DeepSeek V4-Flash 证明，不改架构、不加参数，仅靠重新后训练就能实现 Agent 能力 6 倍以上提升
是什么：在预训练模型基础上，通过 RLHF/RLAIF/SFT 等方法针对特定场景优化模型行为
怎么使用：构建场景化训练数据 → 设计奖励函数 → RL 训练 → 评估迭代
最佳实践：清华 JustGRPO 算法表明，后训练阶段回归简单方法（如自回归顺序+GRPO）反而更有效
容易踩坑：过度优化特定基准导致泛化能力下降；奖励函数设计不当导致 reward hacking
推荐资料：DeepSeek V4-Flash 技术报告、清华 JustGRPO 论文 (arxiv.org/abs/2601.15165)
学习时间：15 分钟即可掌握核心概念

知识点 2：Effort 档位 — 推理强度的动态调节

为什么需要：不同任务对推理深度需求不同，固定模式要么浪费成本要么能力不足
是什么：Claude Opus 5 引入的低/中/高三档推理强度，自主平衡速度、成本与推理深度
怎么使用：API 请求中设置 effort 参数；低档快速响应省 Token，高档深度思考+自主校验
最佳实践：简单查询用低档，复杂编程/分析用高档，批量任务用中档
容易踩坑：所有任务都开最高档导致成本失控；低档处理复杂任务导致质量下降
推荐资料：Anthropic Opus 5 官方文档
学习时间：15 分钟即可掌握

知识点 3：MCP（Model Context Protocol）集成模式

为什么需要：Agent 需要连接外部工具和数据源，缺乏标准协议导致集成成本高
是什么：标准化的模型上下文协议，让 Agent 以统一方式发现和调用工具
怎么使用：注册 MCP Server → Agent 自动发现工具 → 按需调用；Copilot SDK 原生支持
最佳实践：将企业内部 API 封装为 MCP Server，实现 Agent 与业务系统的标准化对接
容易踩坑：工具粒度过细导致 Agent 选择困难；权限控制不当导致安全风险
推荐资料：Copilot SDK 文档、Kimi K3 MCPMark 评测
学习时间：15 分钟即可掌握概念
